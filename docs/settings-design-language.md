# 设置内容区设计语言

右侧内容区沿用 Windows 系统浅色和深色外观。亚克力保留在窗口底层，内容卡片用更高不透明度的中性色承载文字，同级双栏继续使用相同间距。卡片采用 8 DIP 圆角，卡片之间通过留白和明度区分。[Microsoft Acrylic](https://learn.microsoft.com/en-us/windows/apps/design/style/acrylic)

交互控件采用 4 DIP 圆角。按钮、下拉框和快捷键输入共用中性色填充、细描边、悬停反馈和按下反馈。选中、开启及主要操作使用蓝色，危险操作文字使用红色。禁用状态降低对比且保留默认光标，普通可点击按钮使用手形光标。[WinUI 控件](https://learn.microsoft.com/windows/uwp/design/controls-and-patterns/) · [WinUI ComboBox](https://learn.microsoft.com/windows/apps/design/controls/combo-box) · [Google Material 色彩角色](https://m3.material.io/styles/color/the-color-system/)

标题、正文、辅助文字和禁用文字使用各自的颜色角色。辅助文字在浅色模式用深灰，在深色模式用浅灰，通过颜色和间距建立信息层级。下拉菜单和对话框使用不透明表面，选中状态同时提供填充与文字反馈。通用状态由共享绘制方法实现，内置设置和插件设置使用同一套规则。[Meta 无障碍设计](https://www.meta.com/design-at-meta/blog/acessibility-and-design-systems/) · [Adobe Spectrum 设计令牌](https://spectrum.adobe.com/page/design-tokens/)
